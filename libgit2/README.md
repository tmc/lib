# libgit2

Go bindings for libgit2, generated by `github.com/tmc/libgen/cmd/gen-libgit2`.
The source headers are libgit2 v1.9.6, commit
`26055f5af74ab1cf636d272e8a34315496d3f06f`.

Call `Load(path)` and check its error before making native calls. Use `Has` for
optional symbols. Pair `Libgit2Init` with `Libgit2Shutdown`, and free all native
resources before shutdown. Negative status values indicate C errors. These are
low-level bindings: pointer, callback, and ownership rules follow the C API.
Wrappers return a Go error if their library or symbol is unavailable. C status
returns remain separate from that error.

Regenerate from the sibling codegen checkout:

```sh
go -C ../../codegen run ./cmd/gen-libgit2 \
  -header "$HOME/tmp/libgit2/include/git2.h" -output ../lib/libgit2 \
  -facade-import github.com/tmc/lib/libgit2
GOWORK=off go test ./...
```

`LIBGIT2_TEST_LIBRARY=/absolute/path/to/libgit2.dylib GOWORK=off go test ./...`
also runs repository/blob round trips verified by the Git CLI and error cases.
Without that variable native tests skip; layout tests still run. Generation and
native calls were verified on macOS arm64. See the generator README for build
instructions and limitations.
