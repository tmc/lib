# treesitter

Go bindings for the [tree-sitter](https://tree-sitter.github.io/) parsing
library, loaded at run time with purego. No cgo.

```go
tree, err := treesitter.ParseFile("main.c")
defer tree.Close()

q, err := treesitter.NewQuery(tree.Language(), `
    (call_expression function: (identifier) @callee
      (#match? @callee "^str"))`)
defer q.Close()

for m := range q.Matches(tree.RootNode()) {
	fmt.Printf("%s at %v\n", m.Text("callee"), m.Node("callee").StartPoint())
}
```

The API is shaped for Go rather than translated from C:

- A tree remembers its source, so `Node.Text()` takes no argument.
- Children, descendants, errors, matches, captures, and lookahead symbols
  are range-over-func iterators.
- Counts and byte offsets are `int`, not `uint32`.
- Node is a value type and every method accepts a null node, so
  `n.ChildByFieldName("x").Text()` is safe.
- `Query.Matches` names captures and applies text predicates; a malformed
  predicate is a compile error. `QueryCursor` still exposes the raw
  tree-sitter behaviour.
- `ParseFile` picks a grammar from the file name; `Parse` is a one-call
  parser for a language you already have.
- Streaming input is `io.ReaderAt`, because tree-sitter reads by byte
  offset and revisits earlier offsets; a forward-only `io.Reader` cannot
  serve it.

The package covers parsing (whole-buffer, chunked, random-access,
incremental, and context-cancellable), tree and node inspection, tree
cursors, queries with named captures and predicate evaluation, lookahead
iteration, and language introspection. The WebAssembly grammar loader and
the custom allocator are not bound.

## Libraries

`libtree-sitter` is located through `TREE_SITTER_LIB_PATH`, then the
platform default search path, then the common Homebrew paths on macOS.
`Load` sets the path explicitly. Grammars are separate shared libraries
exporting `tree_sitter_<name>`. `FindLanguage` looks one up by name in
`TREE_SITTER_GRAMMAR_PATH`, the tree-sitter CLI's library directory, the
parser directories of Neovim and Emacs, and the system library directories
(`GrammarDirs` lists them); `LoadLanguage` opens one by path.

If no grammar is installed, `treesitter/grammars` builds one:

```go
if _, err := grammars.Install(ctx, "go"); err != nil {
	log.Fatal(err)
}
tree, err := treesitter.ParseFile("main.go")
```

`Install` downloads a pinned source archive, checks it against a recorded
SHA-256, compiles it, and writes the library where `FindLanguage` looks.
Upstream publishes C source rather than binaries, so this needs a C
compiler at install time; parsing still needs none. `grammars.All` lists
what is pinned, and `Grammar.Build` installs a grammar that is not.
The pins cover the common languages plus `cuda`, `ptx`, `glsl`, `hlsl`,
`swift`, `objc`, `starlark`, and tree-sitter's own `query` language.
The package is separate so that a program which only parses links no HTTP
client and no parse can reach the network.

tree-sitter has no notion of which language a file is written in.
`DetectLanguage` maps a file name to a grammar name using the extensions
the common grammars declare, which is what the tree-sitter CLI does with
its `file-types` lists.

A grammar's ABI version must lie within the range this library supports
(`MinCompatibleLanguageVersion` through `LanguageVersion`). Grammars built
by the tree-sitter CLI, and the parsers Neovim installs, satisfy this.

## Platforms

Linux and macOS on amd64 and arm64, the targets on which purego passes
structs by value. `Load` fails elsewhere. `manual-gates.md` records which
configurations the live tests have been run on.

## Layout

`internal/ts` is generated by `gen-treesitter` from
`github.com/tmc/codegen` and binds `tree_sitter/api.h` one function to one
Go function. The public package is written by hand on top of it. To
regenerate:

```sh
gen-treesitter -header $PREFIX/include/tree_sitter/api.h -output treesitter/internal/ts
```

`grammars/pins.gen.go` is generated by `grammars/mkmanifest.go`, which
resolves each grammar repository's latest release and records the archive's
digest:

```sh
go generate ./grammars
```

## Testing

The generated layout tests run everywhere. The remaining tests need the
library and a C grammar and skip otherwise; see `manual-gates.md`.
