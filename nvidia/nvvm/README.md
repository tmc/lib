# NVVM

Go bindings for NVIDIA's NVVM compiler, generated by codegen's
`gen-nvidia -api nvvm`. Use NVVM for NVVM IR; use `nvrtc` for CUDA C++.

Create a `Program`, add IR and libdevice with `AddModuleTo` or
`LazyAddModuleTo`, call `Compile`, and retrieve `GetCompiledResult`.
`GetProgramLog` returns compiler diagnostics. `DestroyProgram` takes the
address of the handle. Keep lazily supplied buffers alive through compilation.

`Compile([]string{"-arch=compute_120", "-gen-lto"})` produces LTOIR for
`nvjitlink`. Host-visible entry points must be retained through device LTO;
the test IR includes `llvm.used` for that purpose, as cuda-oxide does.

The generated surface uses the CUDA 13.2.51 NVVM header, including
`LLVMVersion`. Loading is lazy. Set `NVVM_LIB_PATH` to select a library before
its first use. Older libraries remain usable; unavailable functions return
`*SymbolError`. `LLVMVersion` is absent from the tested CUDA 13.0 library.

## Validation

From the `nvidia` module root on Linux with an NVIDIA GPU and CUDA 13:

```sh
export CUDA_HOME=/usr/local/cuda-13
export NVVM_LIB_PATH="$CUDA_HOME/nvvm/lib64/libnvvm.so.4"
export NVJITLINK_LIB_PATH="$CUDA_HOME/lib64/libnvJitLink.so.13"
export CUDA_LIBDEVICE="$CUDA_HOME/nvvm/libdevice/libdevice.10.bc"
CUDA_COMPILER_TEST=1 GOWORK=off go test -tags cuda -v \
  ./nvvm ./nvjitlink ./driver -count=1 -timeout=120s
```

The pipeline test selects the GPU's compute capability, compiles a sine kernel
with libdevice, links LTOIR to cubin, loads and launches it, and checks all 128
results against `math.Sin`. It also encodes a two-dimensional tensor map,
replaces its address, and checks malformed IR rejection and compiler logs.
The `cuda` tag enables runnable examples with checked output.

Set `CUDA_ARTIFACT_DIR` to a persistent scratch directory to retain the LTOIR
and cubin. The test logs input and output SHA-256 digests. Without
`CUDA_COMPILER_TEST=1`, the GPU test skips; this does not prove GPU execution.
Ordinary package tests cover import behavior and missing-library/symbol errors.

The test IR uses the modern NVVM dialect for Blackwell; runtime evidence was
collected on GB10 (`sm_121`). Other architectures and Windows were not tested.
