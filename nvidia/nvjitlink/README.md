# nvJitLink

Go bindings for NVIDIA device-code linking, generated by codegen's
`gen-nvidia -api nvjitlink`.

Create a linker with `Create`, add LTOIR, PTX, or binary inputs with
`Handle.AddData` or `Handle.AddFile`, call `Handle.Complete`, and retrieve
`Handle.GetLinkedCubin` or `Handle.GetLinkedPtx`. Error and information logs
are available on the handle. Release it with `Destroy(&handle)`.

The generated bindings use CUDA 13.0.88's header and its `__nvJitLink*_13_0`
exports. These are actual library symbols; the unsuffixed public names in
`nvJitLink.h` are inline forwarding functions. Set `NVJITLINK_LIB_PATH` before
first use to select the library explicitly. Missing symbols return
`*SymbolError`.

See [NVVM validation](../nvvm/README.md#validation) for a complete
NVVM IR → LTOIR → cubin → GPU launch test and a runnable PTX linking example.

Regenerate the 13.0 baseline from the codegen repository with:

```sh
go run ./cmd/gen-nvidia -api nvjitlink \
  -header ../cuda-headers/pinned/nvjitlink/cuda-13.0/nvJitLink.h \
  -output ../lib/nvidia/nvjitlink
```

The default header may select newer versioned symbols and therefore raise the
minimum runtime requirement. Updating it requires a separate compatibility check.
