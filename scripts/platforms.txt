#
#	<module directory> <GOOS/GOARCH>...
#

# target listed here is one the repository promises to keep compiling. The
# list must name every module in go.work and no others.

# for a target does not thereby have a tested runtime on it; RELEASE.md
# records which platforms were exercised against real hardware.

# ship no windows source at all and have never claimed it.
